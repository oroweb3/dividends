# Historical dividend inspection methodology

An early read-only investigation compared an issuer cash-dividend event with the Solana mint multiplier and provider-indexed token activity. Personal wallet identifiers, transaction identifiers and exact holdings are withheld from the public repository.

The exercise established that previously accumulated multiplier value must be included in the pre-dividend exposure. A current balance or historical acquisition alone does not establish eligibility. Current application checks additionally require enrollment timing, baseline lineage, unchanged holdings, and complete provider-indexed activity evidence.

This investigation did not enroll an account, authorize a conversion or prove the full automated dividend lifecycle.
